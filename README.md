# marionette-agent

Observe, operate, and verify Marionette-enabled Flutter apps through a Dart CLI or stdio MCP server.

Marionette対応Flutterアプリを観測・操作し、結果を確かめるためのCLIとstdio MCPサーバーです。現在の対応ホストはmacOS、対象はMarionette bindingを初期化したdebugアプリです。
