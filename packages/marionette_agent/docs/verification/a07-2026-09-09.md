## Simulator実行

operation_confirmationで以下を実行。認証URIは一時ファイルから検証runnerが読み込み、証跡には記載しない。

```sh
flutter run -d 59AA2C66-0A43-4E6B-9B63-63B7E38F72F9 --debug --no-pub \
  --vmservice-out-file=/tmp/mra-a07-uri
```

各CLIコマンドはパッケージの `dart bin/marionette_agent.dart --json --session sim` を別プロセスで実行し、専用 `MARIONETTE_AGENT_RUNTIME_DIR=/tmp/mra-a07-runtime` を共有した。

| コマンド | 期待結果 | 実際の結果 |
| --- | --- | --- |
| `connect <VM_URI>` → `snapshot` | 接続を別CLI間で保持、Page 1とpage_viewのrefを取得 | 成功、Page 1 |
| `swipe <page_view ref> left --distance 300` → `snapshot` | 一度送信、Page 2へ切替 | exit 0 / requiresSnapshot、Current page: 2 |
| 同じrefで `swipe <ref> left` | STALE_REFで送信しない | exit 4 / not_sent |
| `swipe --start-x 100 --start-y 556 --end-x 350 --end-y 556` → `snapshot` | 座標方式でPage 1へ戻る | exit 0、Current page: 1 |
| `swipe --key dismissible_item left --distance 200` → `snapshot` | アイテムを削除 | exit 0、Item dismissed |

最初にPageViewを200pxで操作した際はexit 0でもPage 1へ戻った。ジェスチャー完了はページ切替の保証ではなく、SPECどおり次のsnapshotで検証する。新snapshotのrefを取得して300pxを指定した別の操作で切替を確認した。CLIによる自動再送や距離調整は行わない。
