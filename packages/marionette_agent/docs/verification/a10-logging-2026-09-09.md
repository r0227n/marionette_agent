# A10 Logging Verification — 2026-09-09

Owner: GPT-5 Codex.

## Contract

- Emit `package:logging` records at INFO or above on the invoking CLI's stderr.
- Keep stdout limited to the CLI result envelope.
- Redact HTTP(S)/WS(S) URIs and omit attached errors and stack traces.
- Suppress records below INFO because the fixed upstream connector logs extension arguments, including entered text, at FINE.
- Associate daemon records with the request Zone so concurrent sessions do not receive one another's diagnostics.
