## Make every interaction observable

marionette-agent is a Dart CLI for operating Marionette-enabled Flutter apps. Agents and people use the same commands to locate elements, enter text, send gestures, and inspect what changed.

```sh
marionette-agent snapshot
marionette-agent tap --key tap_button
marionette-agent snapshot
```

This is the smallest interaction loop for the connected example app. Check the second observation to see that the tap count increased.
