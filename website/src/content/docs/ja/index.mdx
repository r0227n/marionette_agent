## 画面の変化を、確認できる操作に

marionette-agentは、Marionette対応のFlutterアプリを操作するDart製CLIです。エージェントも人も、同じコマンドで要素を探し、入力やジェスチャーを送り、画面の変化を確認できます。

```sh
marionette-agent snapshot
marionette-agent tap --key tap_button
marionette-agent snapshot
```

接続済みのexampleアプリで使う最小の流れです。2回目の観測でタップ数が増えたことを確認します。
